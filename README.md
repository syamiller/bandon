# Bandon

Trip hub for the **Nov 15–18, 2026** Bandon week: tee schedule, individual trip points (match wins + skins every round), and mixed per-round formats.

## Quick start

```bash
npm install
npm run dev
```

## The four

**Simon, Zach, Emory, Sammy** — edit in [`src/data/trip.ts`](src/data/trip.ts).

## How scoring works

No fixed trip teams. Everyone banks their own points from:

- **Match wins** — best ball, Nassau, Wolf, 6-hole 1v1s, closest-to-the-pin
- **Skins** — every hole, every round (carryovers stack)

## Round formats

| Round | Course | Format |
|-------|--------|--------|
| Nov 15 am | Bandon Trails | Best ball match |
| Nov 15 pm | Bandon Preserve *(short)* | Closest to the pin |

| Nov 16 pm | Bandon Dunes | Sixes · 1v1 |
